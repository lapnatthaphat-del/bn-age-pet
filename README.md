# PetAge — เทียบวัยน้องกับเรา

เว็บ static ภาษาไทยสำหรับคำนวณอายุจริงของสัตว์เลี้ยง และแสดงอายุเทียบเท่าคนแบบอัปเดตทันทีจากวันเกิด รองรับสุนัข แมว สัตว์ขนาดเล็ก นก และสัตว์ Exotic

ผู้ใช้สามารถเพิ่มสัตว์เลี้ยงหลายตัวเป็นการ์ดพร้อมรูปส่วนตัวได้ รูปจะถูกย่อในเบราว์เซอร์ก่อนเก็บไว้ในอุปกรณ์ของผู้ใช้

เว็บแบ่งเป็น 4 หน้าหลัก: สัตว์เลี้ยงของฉัน, เพิ่มสัตว์, วิธีคำนวณ และแหล่งอ้างอิง โดยทุกหน้าใช้ข้อมูลสัตว์เลี้ยงชุดเดียวกันใน `localStorage`

## พัฒนาและทดสอบ

```bash
npm test
npm run serve
```

จากนั้นเปิด `http://localhost:4173`

ข้อมูลทั้งหมดคำนวณในเบราว์เซอร์และเก็บเฉพาะใน `localStorage` ของอุปกรณ์ผู้ใช้
